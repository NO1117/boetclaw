# 模型能力与运行性能完善计划

## 目标

在现有模型切换、附件检索和 Agent 工作区基础上，补齐模型能力判断、附件兼容性、运行用量指标和隔离 Agent 图缓存，使用户在发送前知道模型是否适合当前输入，发送后能理解本次运行的耗时与资源使用。

## 当前基线

- 后端测试：233 项通过。
- 前端测试：49 项通过。
- 端到端测试：10 项通过（关闭重试）。
- 已支持请求级模型覆盖、图片/文档/文件夹附件、浏览器语音输入与朗读。
- 当前模型元数据较少，前端只突出视觉能力；隔离 Agent 每次构图，运行指标未形成面向用户的统一数据。

## 本期范围

### 1. 统一模型能力描述

- 扩展模型信息：上下文窗口、最大输出、工具、视觉、音频输入/输出、结构化输出、本地模型、可选输入/输出单价。
- 能力使用三态语义：`true`、`false`、`unknown`；未知不得等同于不支持。
- 静态供应商声明与现有能力缓存合并，动态探测结果可覆盖静态默认值，并保留来源与更新时间。
- API 响应保持向后兼容，前端旧字段仍可读取。

### 2. 输入兼容性判断

- 根据待发送附件推导硬性需求：图片需要视觉能力；普通文档、表格、演示文稿和文件夹使用现有文本抽取/检索，不强制原生文件能力。
- 模型选择器展示能力标签、上下文窗口及兼容状态；明确不兼容的模型禁用并说明原因，能力未知时提示但允许选择。
- 后端在执行前进行同源校验，避免绕过前端；返回结构化、可展示的错误信息。
- 切换附件或模型后即时重新计算状态，不丢失用户当前输入。

### 3. 隔离 Agent 图缓存

- 为请求级模型覆盖引入有界 LRU + TTL 缓存，键至少包含 Agent、供应商、模型、技能/配置指纹和检查点身份。
- 并发构建采用单飞或等价锁机制，避免同一个键重复构图。
- 供应商配置变化、技能重载、Agent 删除/清理时精准失效；默认图路径保持现有行为。
- 不把明文凭据写入缓存键、日志或指标。
- 暴露命中、未命中、构建耗时、当前大小和驱逐次数，默认参数可配置。

### 4. 运行指标与用户反馈

- 记录开始、首个输出、完成时间；输出首字延迟和总耗时。
- 从供应商响应的 usage metadata 提取输入、输出、总 token；缺失值返回 `null`，不伪造为 0。
- 仅在配置了价格且 token 可用时估算费用，并标注为估算值。
- 记录供应商、模型、图缓存状态、附件数、检索命中数和 trace id。
- 将本次运行摘要随流式完成事件返回，并提供按 trace id 查询详情的只读接口；不得暴露提示词、附件正文或密钥。
- 前端右侧上下文区展示“本次运行”卡片：模型、首字/总耗时、token、估算费用、缓存状态；缺失信息显示“暂无数据”。

### 5. 质量与兼容性

- 后端覆盖能力合并、三态兼容判断、缓存命中/失效/并发、usage 缺失和费用估算。
- 前端覆盖模型禁用原因、unknown 提示、指标空态与完成态。
- 端到端覆盖图片附件模型过滤、兼容模型发送、完成后展示运行指标。
- 保持既有 API、普通聊天、附件上传/检索和浏览器语音功能不回归。

## 页面设计要求

- 沿用当前深色工作区，不新增独立设置页。
- 模型下拉项采用“名称 + 能力标签 + 上下文”三层信息结构，标签克制且可扫读。
- 当前输入不兼容时，在选择器下方显示就地警告和可执行建议。
- “本次运行”卡片置于右侧上下文栏，数值按首字延迟、总耗时、输入/输出 token、估算费用、图缓存分组。
- 桌面端优先；窄屏时卡片进入现有侧栏折叠逻辑，不遮挡输入框。

## 验收标准

1. 图片待发送时，明确不支持视觉的模型不可选，并显示中文原因；能力未知的模型可选但有风险提示。
2. 后端拒绝不兼容请求时返回稳定错误码和缺失能力列表。
3. 相同隔离 Agent 配置连续执行时第二次命中图缓存；配置或技能变化后不复用旧图。
4. 并发相同键只构建一次；缓存达到上限后按 LRU 驱逐，TTL 到期后重建。
5. 完成事件和查询接口均能返回同一 trace 的运行摘要；usage 不可得时 token/费用为 `null`。
6. 前端可展示完整指标和空态，且不显示凭据、提示词或附件正文。
7. 后端、前端、构建和端到端测试全部通过，端到端测试关闭重试。

## 非目标

- 本期不接入新的 STT/TTS 服务端供应商。
- 不做真实账单或结算，费用只做可选估算。
- 不抓取供应商实时价格；价格由受控配置提供。
- 不引入分布式图缓存或跨实例指标聚合。

## 实施顺序

1. 扩展能力模型、供应商元数据和兼容判断。
2. 实现图缓存及失效机制。
3. 接入运行指标采集与 API/流式事件。
4. 按 Figma 设计更新模型选择器与右侧运行卡片。
5. 补齐测试、文档和配置示例，执行完整回归。
