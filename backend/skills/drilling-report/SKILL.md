# 钻井报告技能

## 适用场景

- 钻井日报/周报撰写
- 完井报告生成
- 事故报告审查
- 作业总结文档

## 报告结构模板

### 钻井日报

1. **基本信息**：井号、日期、井深、层位
2. **钻井参数**：钻压、转速、排量、泵压、扭矩
3. **进尺情况**：日进尺、累计进尺、机械钻速
4. **井况描述**：岩性、显示、异常
5. **下步计划**：目标层位、预计进尺

### 审查要点

- 参数是否在合理范围内
- 异常事件是否完整记录
- HSE 信息是否齐全
- 数据前后是否一致

## 输出规范

- 使用 Markdown 格式
- 数值保留合理精度
- 关键参数标注单位
