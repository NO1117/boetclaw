# HSE 合规检查技能

## 适用场景

- 钻井作业 HSE（健康、安全、环境）合规审查
- 作业方案安全要素核查
- 事故报告完整性检查

## 检查清单

### 必备安全要素
- [ ] 井控措施与防喷器配置
- [ ] 硫化氢（H2S）监测与防护
- [ ] 应急预案与逃生路线
- [ ] 个人防护装备（PPE）要求
- [ ] 高风险作业许可（动火/受限空间/高处）

### 环境要素
- [ ] 钻井液/废弃物处理方案
- [ ] 泄漏应急响应
- [ ] 噪声与排放控制

## 输出规范

- 逐项检查结果（符合/缺失/待确认）
- 红线项优先标注
- 整改建议与责任提示
